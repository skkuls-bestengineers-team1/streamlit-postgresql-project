# 🎬 Movie Information Analysis Dashboard

SKKU AI CAMPUS Team Project

영화 데이터를 PostgreSQL에 저장하고 SQL을 활용하여 분석한 결과를 Streamlit으로 시각화하는 데이터 분석 프로젝트입니다.

---

## Project Overview

- 영화 정보 데이터 관리
- PostgreSQL 기반 데이터 분석
- Streamlit 대시보드 구현
- GitHub 협업

---

## Tech Stack

- Python
- PostgreSQL
- Streamlit
- Pandas
- Git / GitHub

---

## Main Features

- 영화 정보 조회
- 장르별 분석
- 국가별 분석
- 연도별 분석
- 배급사 분석
- 데이터 시각화

---

## Getting Started

### Clone

```bash
git clone https://github.com/skkuls-bestengineers-team1/streamlit-postgresql-project.git
```

### Install

```bash
pip install -r requirements.txt
```

### Run

```bash
streamlit run frontend.py
```
